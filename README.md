# NurseFlow

AI-powered study and productivity platform for healthcare students.

## Goal

NurseFlow is a backend-focused full-stack project designed to help healthcare students organize courses, track study sessions, manage study tasks, and generate AI-powered practice quizzes.

## Planned Tech Stack

### Backend
- Python
- FastAPI
- Pydantic
- Supabase
- OpenAI

### Frontend
- React
- TypeScript
- Vite
- Tailwind CSS

### Engineering
- Git
- GitHub
- pytest
- Ruff
- Docker
- GitHub Actions

## Project Structure

- `backend/` — Python/FastAPI backend
- `frontend/` — React/TypeScript frontend
- `supabase/` — database migrations and Supabase configuration
- `docs/` — technical documentation
- `.github/workflows/` — CI/CD workflows
